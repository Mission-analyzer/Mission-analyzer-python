# Mission Analyzer

Десктопний застосунок для аналізу польотних місій ArduPilot / Mission
Planner (`.waypoints`, формат QGC WPL 110) перед вильотом безпілотника.

Перевіряє:

- критично низьку висоту польоту — як за даними самого файлу місії, так
і за рельєфом SRTM (по всій лінії польоту між точками, а не тільки в
самих точках);
- занадто гострі кути повороту;
- кут набору/зниження (flight path angle) поза допуском;
- глісаду заходу на посадку — дистанцію/азимут/кут по останніх
відрізках до `LAND`, з урахуванням команд `DO_CHANGE_SPEED`.

## Встановлення (готовий `.exe`)

Не обов'язково ставити Python і запускати з коду — для Windows є
готова портативна збірка, нічого встановлювати додатково не треба.

1. Відкрий сторінку **[Releases](https://github.com/Mission-analyzer/Mission-analyzer-python/releases)**
   і завантаж `.zip`-архів останньої версії (наприклад
   `MissionAnalyzerV103.zip`).
2. Розпакуй архів у будь-яку папку (можна прямо на флешку — програма
   портативна, нічого не пише поза своєю папкою, крім `settings.json`
   поруч із `.exe`).
3. Запусти сам `.exe` усередині розпакованої папки.

**Windows покаже попередження — це нормально, не сигнал про вірус.**
Програма не підписана комерційним сертифікатом (він платний і не
потрібен для невеликого відкритого проєкту), тому при першому запуску
з'явиться вікно **«Windows захистила ваш комп'ютер»** (SmartScreen).
Щоб запустити:

1. Натисни **«Докладніше»** («More info») у цьому вікні.
2. З'явиться кнопка **«Виконати попри все»** («Run anyway») — натисни
   її.

Це стандартна поведінка Windows для будь-якого непідписаного `.exe`,
незалежно від того, наскільки він насправді безпечний — сертифікат
підпису коштує грошей на рік і ніяк не пов'язаний із реальною
безпекою коду. Якщо хочеш перевірити сам файл — увесь код відкритий
просто тут, у цьому репозиторії.

## Вимоги

(Це для запуску **з коду**, розробникам — якщо тобі достатньо готового
`.exe` з розділу вище, цей блок можна пропустити.)

- Windows, Python 3.11+ (стандартна бібліотека: `tkinter`, `urllib`,
`json`; додатково: `Pillow` — опційно, для якіснішого масштабування
логотипу/скріншотів).
- Інтернет для довантаження тайлів карти (OpenStreetMap / Google) і
тайлів рельєфу SRTM за потреби (див. нижче).

Встановити залежності:

```
pip install -r requirements.txt
```

## Запуск

```
python main.py
```

## Тайли SRTM (рельєф)

Тайли рельєфу **не зберігаються в репозиторії** (це гігабайти
бінарних даних, не код). Замість цього `srtm.py` сам довантажує
потрібний тайл з публічного дзеркала `terrain.ardupilot.org` (тим самим, яким для докачки тайлів користується сам Mission Planner)
у момент, коли тайл дійсно знадобився для аналізу маршруту — і кладе
його в локальну папку SRTM поруч з рештою.

Шлях до папки з тайлами задається на сторінці **Конфігурація** в
самому застосунку.

Якщо в папці вже накопичилась повна світова база SRTM і хочеться
лишити тільки потрібний регіон (наприклад Україну та Росію) —
скористайся `cleanup_srtm.py`:

```
python cleanup_srtm.py "шлях\до\папки\SRTM" --apply
```

Без `--apply` скрипт лише покаже, скільки файлів і гігабайт буде
перенесено (dry-run).

## Структура проекту

| Файл                                                    | Відповідальність                                                                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `main.py`                                               | Точка входу, сплеш-екран                                                                                                       |
| `app.py`                                                | Головне вікно: шапка, навбар, каркас сторінок, перемикання мови                                                                |
| `mission_page.py`                                       | Сторінка «Місія»: таблиця вейпоінтів, завантаження/збереження `.waypoints`, підключення до ArduPilot (MAVLink), карта маршруту |
| `analysis_page.py`                                      | Сторінка «Аналіз»: вкладки зліт/маршрут/посадка, метео, графіки, PDF-звіт                                                      |
| `config_page.py`                                        | Сторінка «Конфігурація»: параметри аналізу, шляхи SRTM/кеш карти, провайдер карти                                              |
| `help_page.py`                                          | Сторінка «Довідка»: changelog, перевірка оновлень                                                                              |
| `waypoints.py`                                          | Парсинг/запис `.waypoints` (QGC WPL 110)                                                                                       |
| `geo.py`                                                | Геометрія: відстані, азимути, інтерполяція вздовж маршруту                                                                     |
| `srtm.py`                                               | Читання рельєфу з тайлів SRTM + автодокачка відсутніх тайлів                                                                   |
| `analyzer.py`                                           | Основна логіка аналізу місії, генерація звіту                                                                                  |
| `elevation_view.py`, `angle_view.py`, `landing_view.py` | Графіки висоти, кута траєкторії, глісади                                                                                       |
| `map_view.py`, `online_tiles.py`, `overview_map.py`     | Тайли карти (OSM/Google), кеш, відмальовка                                                                                     |
| `occupied_layer.py`                                     | Шар окупованих територій / лінії зіткнення (deepstatemap.live)                                                                 |
| `i18n.py`                                               | Локалізація UA/EN                                                                                                              |
| `theme.py`, `icons.py`                                  | Оформлення в стилі Mission Planner                                                                                             |
| `settings.py`                                           | Збереження/читання `settings.json`                                                                                             |
| `meta.py`                                               | Версія програми та changelog                                                                                                   |
| `updater.py`                                            | Перевірка та застосування оновлень                                                                                             |
| `cleanup_srtm.py`                                       | Допоміжний скрипт очищення папки SRTM від зайвих регіонів                                                                      |

`settings.json` генерується самим застосунком при першому запуску і
в репозиторій не входить (див. `.gitignore`).
